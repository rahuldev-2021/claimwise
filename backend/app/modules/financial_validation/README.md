# Financial Validation Module (Phase 6)

Estimates expected parts cost and labour hours using **separate** ML pipelines, compares submitted values using **PROVISIONAL** rules, and returns explainable statuses for human reviewers.

- Does **not** approve or reject claims
- Does **not** label fraud
- Does **not** fabricate predictions when models are missing

See [`../../../docs/phase6_financial_validation.md`](../../../docs/phase6_financial_validation.md).

Configuration: [`../../../config/financial/`](../../../config/financial/) (**PROVISIONAL**).
